Integritetspolicy

Gäller från 19 oktober 2026.

1. Vilka uppgifter

Analysverktyg — Yandex Metrica (Yandex LLC, Ryssland) och Google Analytics (Google Ireland Ltd) — använder kakor för att registrera IP-adress, uppgifter om webbläsare och enhet, varifrån besöket kom, klick och skrollning. Båda laddas via Google Tag Manager, som inte själv sätter kakor. Om du själv lämnar din e-postadress på betalsidan sparas den i Yandex Forms (Yandex LLC, Ryssland). Webbplatsen samlar inte in andra uppgifter. Webbplatsens server (GitHub Pages, GitHub, Inc., USA) tar tekniskt emot IP-adressen.

2. Ändamål och rättslig grund

Att räkna vilka funktioner och paket besökare är intresserade av innan tjänsten byggs (art. 6.1 f GDPR); e-postadressen — ett meddelande när tjänsten startar, med ditt samtycke som du ger genom att skicka fältet (art. 6.1 a GDPR).

3. Överföring utanför EES

Uppgifter kan föras över till Ryssland (Yandex) och USA (Google, GitHub). För Ryssland finns inget beslut från Europeiska kommissionen om adekvat skyddsnivå.

4. Lagringstid

Analysuppgifter — enligt verktygens inställningar, högst 14 månader; e-postadressen — tills meddelandet om start har skickats eller tills beslut fattats att inte starta tjänsten.

5. Dina rättigheter

Tillgång, rättelse, radering, begränsning, invändning och återkallat samtycke (art. 15–21 GDPR); klagomål till Integritetsskyddsmyndigheten (IMY). Du kan blockera kakor i webbläsaren — webbplatsen fungerar ändå.
